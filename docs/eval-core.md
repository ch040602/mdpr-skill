# Eval-core Runner

`eval-core` is the mdpr-skill evaluation runner. It compares MDPR output with
and without accepted skill hints, while preserving MDPR as the deterministic
runtime.

## Flow

```text
Markdown source
  -> MDPR baseline build
  -> sourceSha256 and manifest metrics
  -> schema/boundary checked agent-hint.json
  -> MDPR guided build
  -> regression gate
  -> mdpr-skill-eval-v1 report
```

## Gates

`schemaSync` verifies that the hint manifest is `mdpr-agent-hint-v1`, was
generated by `mdpr-skill`, has a `generatedAt` timestamp, contains a hints
array, and matches the baseline `sourceSha256`.

`boundary` verifies that hints do not contain final decision fields such as
coordinates, colors, typography, z-order, arrows, geometry, exact icon paths,
component variants, recipes, or renderer object IDs.

`regression` compares baseline and guided metrics. A guided build fails the
gate when it increases overflow, coherence warnings, visual errors, text
clipping risk, contrast failures, or connector warnings. It also checks
thresholded build-time, slide-count, output-size, and minimum-font regressions.

## Report

The emitted report uses `schemaVersion: "mdpr-skill-eval-v1"` and records:

- `summary.overallStatus`
- baseline and guided manifest paths
- baseline and guided run artifacts
- `schemaSync`, `boundary`, and `regression` gate findings
- thresholds used for the regression decision
- accepted hint path

The report is evidence for review. It is not a layout or style authority.
