## Account-Gated Channels

These channels require the maintainer's own authenticated account, community
history, or API token before posting. Use
[promotion/contributor-outreach-kit.md](contributor-outreach-kit.md) for copy.

| Channel | Why not posted from Codex | Recommended action |
| --- | --- | --- |
| Hacker News Show HN | Requires maintainer account and direct submission. | Post the Show HN draft manually from the maintainer account. |
| Reddit | Requires subreddit-aware account posting and anti-spam judgment. | Post to one relevant subreddit first, then respond technically. |
| Dev.to | Requires a Dev.to API key or authenticated author session. | Publish a short article using the outreach kit. |
| Product Hunt | Requires maker profile, launch scheduling, and media setup. | Prepare launch after more user examples are collected. |
| Mastodon/Bluesky/X | Requires account token or logged-in client. | Use the short social post from the outreach kit. |
