Decoration Selection Inputs
  • ConstraintLong text should use plain-safe or rail layouts instead of decorative cards.
  • EvidenceImportant proof points may receive a contrast chip, but sibling objects keep one grammar.
  • Image needImage sidecars are reserved only when the source contains or requires an image.
  • DensityDense tables and code blocks reduce decoration before shrinking below the readable font floor.
